# Traduções por arquivo YAML

O texto que o usuário lê não mora mais em XML escrito à mão. Cada idioma é um
arquivo em `android/i18n/`; o build gera os recursos Android correspondentes.

```
android/i18n/pt_br.yml   ->  app/src/main/res/values/strings.xml
android/i18n/en.yml      ->  app/src/main/res/values-en/strings.xml
                             app/src/main/res/values/languages.xml
```

## Formato

```yaml
language: pt-BR          # tag usada pelo seletor e pelo Locale
label: Português (Brasil)
strings:
  diary_title: Seu diário.
plurals:
  timeline_day_count:
    one: '%1$d acontecimento'
    other: '%1$d acontecimentos'
```

Regras:

- o arquivo com mais chaves é a referência; chaves faltando em outro idioma
  aparecem como pendentes no painel (`Aba Idiomas`) e caem no recurso padrão;
- valores com `:` precisam de aspas (`editor_cover_note: 'A capa é...: ...'`);
- placeholders Android (`%1$s`, `%1$d`) são preservados literalmente;
- `language` define a pasta `values-<tag>`; o primeiro catálogo alimenta
  `values/`, usado quando o idioma do aparelho não tem tradução.

## Fluxo

```bash
make i18n        # regenera os recursos a partir dos YAML
make check       # falha se os recursos gerados estiverem defasados
```

O Gradle também roda o build antes de `preBuild`, então `./gradlew assembleDebug`
nunca usa recursos velhos. Os arquivos gerados começam com o marcador
`GENERATED FILE` e são isentos do limite de 200 linhas.

## Adicionar um idioma

1. copie `android/i18n/en.yml` para `<tag>.yml` e ajuste `language` e `label`;
2. traduza as chaves;
3. `make i18n`;
4. abra Ajustes › Idioma no app — a nova língua aparece automaticamente, porque a
   lista vem de `values/languages.xml`, gerado a partir dos catálogos.

A escolha fica em `SharedPreferences` (`diaryteller.preferences`) e é aplicada em
`MainActivity.attachBaseContext`; trocar de idioma recria a activity para que
todas as telas releiam a configuração.

## Por que não `values-en/` escrito à mão

Duas cópias divergem. Com um arquivo por idioma existe uma única fonte, o painel
mostra o que falta e o `make check` impede que o app seja publicado com recursos
defasados em relação ao catálogo.
